🔒 Your data

Waypoints is a single-file travel log — no accounts, no tracking. Everything is stored only in this browser by default. Google Drive sync in Settings is entirely optional and off unless you set it up yourself.

☁️ Setting up Google Drive sync

This is optional, and only needed if you want your log on more than one device. It takes about 5 minutes, once:

  1. Go to console.cloud.google.com and create a new project (any name).
  2. Search for and enable the Google Drive API for that project.
  3. Go to APIs & Services → OAuth consent screen, choose "External," and fill in the required fields.
  4. On that same OAuth consent screen page, scroll to Test users → + Add users, and add every Google account you'll actually sign in with (including your own). This step is easy to miss and is the #1 cause of sign-in errors.
  5. Go to APIs & Services → Credentials → Create Credentials → OAuth client ID, choose "Web application."
  6. Under Authorized JavaScript origins, add the exact URL Waypoints is hosted at (e.g. https://yourusername.github.io — no trailing slash or path).
  7. Copy the Client ID it gives you, paste it into the Google Drive sync box in Settings, and click Connect.

While your app is in "Testing" mode in Google Cloud, only accounts on the Test users list can sign in — which is fine, since this is just for your own devices.

Seeing "Access blocked… has not completed the Google verification process"? That means step 4 above wasn't done for the account you're signing in with. Add it under Test users and try again.
